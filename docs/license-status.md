# License status

There was no LICENSE in the original repository or its three existing commits. Release 2 preserves that status rather than choosing a license for the owner.

The owner can select a license and add its exact terms and copyright holder in a separate reviewed change. Common choices include [MIT](https://choosealicense.com/licenses/mit/), [Apache 2.0](https://choosealicense.com/licenses/apache-2.0/) and [GPL 3.0](https://choosealicense.com/licenses/gpl-3.0/); these have different permissions and obligations. Public visibility alone is not a general open-source license grant. This document does not supply legal advice or grant additional rights.

The downloaded upstream udp2raw source keeps its own license; inspect it before redistributing binaries. The repository does not vendor or attach udp2raw binaries to this release.
